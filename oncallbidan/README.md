# OnCallBidan

Satu pertanyaan untuk bidan: apakah pola on-call malam sudah menggerus tidur dan keluarga?

Isi jaga 14 hari, persalinan lewat tengah malam, jam tidur, cadangan, dan gejala. Sekali bayar Rp14.900 membuka pita **aman / waspada / kritis**, malam yang dilindungi dua minggu ke depan, dan naskah batas ke pasien serta rekan. Bukan nasihat medis dan bukan alat gaji.

## Perintah

```bash
npm install
npm run build
```

Salin `.env.example` menjadi `.env.local` sebelum pembayaran sungguhan. Tanpa kunci Firebase Admin, hasil tersimpan di `.data/` pada mesin yang menjalankan aplikasi.

Deploy situs ini saja, dari folder `C:\oncallbidan` di mesin Windows, setelah Hosting site `oncallbidan` dan Firestore `oncallbidan` (asia-southeast1) ada di proyek `skoolnow-ea6ff`. Batas biaya: `minInstances` 0, `maxInstances` 3, `cpu` 1, memori 512MiB.
