# TawaranAman

Pita tanda untuk tawaran kerja ke luar negeri: aman, waspada, atau bahaya. Sekali bayar Rp9.900. Bukan nasihat hukum dan bukan alat gaji.

Domain: tawaranaman.id  
URL publik: https://tawaranaman.web.app  
Firebase project: skoolnow-ea6ff  
Hosting site: tawaranaman  
Firestore database: tawaranaman (asia-southeast1)

Folder lokal deploy: `C:\tawaranaman`

## Skrip

```bash
npm install
npm run build
```

`npm run deploy` hanya men-deploy hosting target `tawaranaman` di proyek `skoolnow-ea6ff`. Situs Hosting dan database Firestore harus sudah ada.

Batas biaya di `apphosting.yaml` dan `firebase.json`: minInstances 0, maxInstances 3, cpu 1, memory 512MiB, region asia-southeast1.

## Isi produk

Isian: sumber tawaran, negara, visa, biaya dan waktunya, pinjaman, dokumen, akun SISKOP2MI sendiri, kontrak. Hasil terbuka setelah bayar: pita, tanda, langkah cek Migran Aman dan SISKOP2MI, serta naskah menolak. DeepSeek opsional hanya merapikan naskah itu.
